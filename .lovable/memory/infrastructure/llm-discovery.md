name: LLM Discovery Endpoints
description: Auto-generated llms.txt and /api/citations.json for AI/LLM consumption. Triggered on publish via Notion webhook + MCP + Admin refresh.
type: feature
---
Two machine-readable endpoints for AI/LLM crawlers:

1. **`/llms.txt`** — Generated by `supabase/functions/generate-llms-txt/index.ts`, uploaded to `blog-images/llms.txt` storage, served via `netlify/functions/llms-txt.js`. Contains site description, author entity, key pages, and all published articles in EN/BR/ES with localized URLs.

2. **`/api/citations.json`** — Served by `netlify/functions/citations.js` directly from Supabase REST. Returns JSON array of all publications with canonical_url, title, description, dates, tags, featured_image, urls per language.

Regeneration triggers (all fire-and-forget):
- `sync-notion-content` webhook → invokes `generate-llms-txt`
- `mcp-content` upsert (status=published) and delete → invokes `generate-llms-txt`
- Admin "Refresh Feeds" button → invokes `generate-llms-txt`

Static `public/llms.txt` was DELETED — the Netlify redirect at `/llms.txt → /.netlify/functions/llms-txt` (force=true) now serves the dynamic version.
