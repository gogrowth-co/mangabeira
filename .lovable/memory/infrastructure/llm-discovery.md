Two machine-readable endpoints for AI/LLM crawlers:

1. **`/llms.txt`** and **`/llms-full.txt`** — Generated by `supabase/functions/generate-llms-txt/index.ts`, uploaded to `blog-images/llms.txt` / `llms-full.txt` storage, served via the Cloudflare Worker `mangabeira-snapshot-router` storage proxy. Contains site description, author entity, key pages, and all published articles in EN/BR/ES with localized URLs.

2. **`/api/citations.json`** — (Previously served via Netlify; now obsolete — citations data is consumed from `llms-full.txt` and the Supabase MCP server.)

Regeneration triggers (all fire-and-forget):
- `sync-notion-content` webhook → invokes `generate-llms-txt`
- `mcp-content` upsert (status=published) and delete → invokes `generate-llms-txt`
- Admin "Refresh Feeds" button → invokes `generate-llms-txt`

No static `public/llms.txt` — the Cloudflare Worker proxies `/llms.txt` to Supabase Storage with 5-min edge cache.
